# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. Three months, fiber, monthly: 92% churn risk. Then the stake: 338 of 1,000 customers churn. The team cannot call everyone. Who first?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the race: Random forest 0.787, Logistic regression 0.806; Logistic regression wins, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Two models, same 200 held-out rows Sample customer, Predict: 92% churn Safe customer: under 5%
4. **The answer** (68 to 90 s): 0.806, ROC-AUC · logistic regression · 200 held out. And it ships. One limit: Synthetic data: no real customers scored yet. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
